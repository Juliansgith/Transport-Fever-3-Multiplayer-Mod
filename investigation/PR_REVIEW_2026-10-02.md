## Review corrections and evidence

- Unix save cleanup uses `kill(pid, 0)` as an existence query. Only `ESRCH`
  proves absence; permission errors preserve the file. It works without
  Linux's `/proc`, which caused #44's macOS failures.
- Rust and Lua save pickers preserve recovery saves and names that merely
  resemble internal copies. Tests exercise both list discovery and UI options.
- A bound UDP socket that never answers reproduces a reconnect lasting beyond
  its advertised deadline. The regression fails without the attempt timeout
  (three-second outer test deadline), and must pass with it.
- Probe comparison rejects unreadable lanes, conflicting duplicate samples,
  and missing samples within the overlap. Nine synthetic-log cases cover
  matches, differences, empty logs and partial/no overlap.
- Game helpers choose the active or sole Steam account; ambiguity requires an
  explicit path. Existing games/servers are never stopped, quitting never
  force-kills, and staging deletion is restricted to the mod's checked path.
- Windows CI runs the helper parse/probe checks without starting a game.
