# Windows Steam public build 40420: compatibility review, 2026-10-08

The installed public update is game build 40420, Steam build ID 25754343.
The previous selected native bundle is 40408. The hook requires the compiled
bundle's exact executable identity before it installs any native patch, so the
existing multiplayer build refuses 40420. This note records the update review;
static findings alone do not establish runtime compatibility.

`tpfre update --check-only`, comparing complete private source archives for
Steam build IDs 25533170 and 25754343, reported 62 changed files, no added or
removed files, and 58 changed script entries. The executable and three DLLs
changed. Of the 40408 profile's 153 targets, 145 signatures matched uniquely
on the new executable. Seven optional signatures were missing and one optional
call-site prologue changed; no required signature was missing. The audit also
reported 32 changed or unknown containing functions. In particular,
`UI::CMenuUI::StartSavegame` retained its entry signature but changed its
function body. The current hook's shared-save load path uses Lua `app.loadGame`
and the menu's `DoStep`, rather than calling `StartSavegame` directly; the
changed function remains an ABI review item, not evidence that this path broke.
The initial run stopped at both the exact profile and native-bundle gates
before Cargo. After review, the 40420 profile matches all 153 main hook targets
and its six separate diagnostic targets uniquely. `tpfre verify-build` on the
selected 40420 bundle and the complete private 25754343 archive exits 0 with
153 target matches and `review_required: false`; it still reports
`runtime_verified: false`.

The new `gui/menu/main_page.tl` comments out its release-notes icon; the mod's
current injected page already does the same. The game changed company
progression's enforced-rank fallback and cached town growth ratings. The mod's
progression wrapper calls unchanged function signatures and reads its own
company records in a multiplayer room; this still needs runtime confirmation.
The four base subsidy kinds added lightweight card rendering but retained the
event-handler signatures that the mod wraps. The inspected command declarations
did not change. The update generator for the mod's copied main page had fallen
behind the current multiplayer page; rebuilding from the new source would have
restored an older window flow. The generator is corrected and tested with this
update, without copying game sources into Git.

An independent native review checked the changed splice, field, callback and
vtable assumptions against the archived executable bytes before launch. In a
normal local rig run (`update40420-a1`), two 40420 games attached to one
throwaway room. The host saved and reloaded the room world and the guest loaded
that shared save; both advanced from step 1. Renaming the existing line to
"Compatibility Route" through the host's normal UI appeared in the guest's
line manager. Nine common determinism checkpoints through step 2300 had no
different lanes. The Load Game save-details page and Mods tab opened and
displayed both active TPF3-MP mods. This establishes the tested local paths,
not every game action or a public-room upgrade. The release branch and private
game archives remain separate.
