# What the official TF3 docs and mod.io tell us -- 2026-09-29

On release day, before the game unlocked, two sources opened:

- **The official wiki** at <https://wiki.transportfever3.com>, with a
  modding manual and a **generated reference of the whole script API**
  (<https://wiki.transportfever3.com/script-doc/>): `api.cmd`, `api.engine`,
  `api.gui`, `api.res`, `api.type` (with `mod`, `modhub`, `transformator`),
  and the game's own Teal modules (companies, finance, loans, subsidies,
  towns, game time, notifications, the GUI).
- **mod.io** (<https://mod.io/g/transportfever3>), the Mod Hub's backend:
  203 mods, 37 of them script mods, and shared savegames.

Findings are labelled as in [DAY_ONE.md](../docs/DAY_ONE.md). What the
reference documents is **DOCUMENTED**: stronger than REPORTED, since it is
the publisher's own description of the release API, but not yet seen
running. The docs are Urban Games'; this page describes them in our words
and does not copy them.

## The release builds

DOCUMENTED (release notes): **40408 on Steam, 40393 on Epic and GOG**, both
September 29. The stores ship different builds, so the hook needs a profile
for each, and the day-one tools run against each executable. The
GameWatcher mods of the earlier study were made for 40391.

## The command surface

DOCUMENTED: `api.cmd` has 60 command factories. Every command goes through
`api.cmd.sendCommand(cmd, callback, progress)`. From the engine state it
runs at once; from the GUI or console state it runs in the next simulation
step, and its callback fires the frame after. The callback gets the entities
the command made, with their revisions.

How they map to our action schema (`crates/tpf3mp-proto/src/action.rs`):

| our action | the command |
|---|---|
| `BuildRoad`, `BuildTrack`, `BuildConstruction`, `Bulldoze`, `PlaceStop` | `makeWorldBuildProposalCmd` (one proposal for streets, tracks, constructions and removals) |
| `Terraform` | a proposal too, to confirm; `makeWorldReplaceTerrainCmd` replaces the whole terrain (map editor) |
| `BuyVehicle`, `SellVehicle` | `makeVehicleBuyCmd(player, depot, config)`, `makeVehicleSellCmd`; also `makeVehicleReplaceCmd` |
| `CreateLine`, `EditLine` | `makeLineCreateCmd(name, color, player, line)`, `makeLineUpdateCmd`, `makeLineDestroyCmd` |
| `AssignLine` | `makeVehicleSetLineCmd(vehicle, line, stopIndex)` |
| `CompanyOp` | `makeGameAddPlayerCmd`, `makeEntitySetPlayerCmd`, and company scripts through script events |
| speed and pause | `makeGameSetSpeedCmd` |

Not yet in the schema, each refused in a multiplayer game until it has an
action and a checked channel (PLAN Part 3, fail closed):

- vehicles: send to depot, reverse, stop, manual departure, try to depart,
  modifiers;
- names and colours of any entity (`makeEntitySetNameCmd`,
  `makeEntitySetColorCmd`);
- warehouses and stocks (`makeStockList*`, `makeStockSetCargoAmountCmd`);
- industry expansion (`makeCreateIndustryExtendProposalCmd`) and manual
  development;
- script events (`makeScriptingSendEventCmd`);
- the journal, logbooks, `makeWorldSetBulldozableCmd`;
- map-editor and debug commands (towns, terrain, animals, date, time of
  day, weather), which a multiplayer game never sends.

## mod.io

REPORTED, from mod.io's own pages and API:

- **Script mods reach consoles.** Many are published for Xbox and PS5, so
  the Mod Hub takes Lua. Native code still cannot ship through it.
- **Mods that change the world from the GUI** are among the most
  downloaded:
  - Move It and Overpass Builder reshape existing roads and tracks;
  - Planning Fever builds planned track;
  - Timetables holds vehicles for slots "enforced by the game engine" and
    kept in the save;
  - Leasing and Research Fever change the economy.

  They are the case PLAN Part 3 leaves open for the team ("mods that send
  commands from the GUI"). A room that allows one needs its commands
  captured like the stock tools', or the worlds differ.
- **Mods keep state per save** (Improved Destination Displays migrates its
  settings "the first time you load a save").
- **Savegames are shared on mod.io** (tagged Savegame and Map). They are
  candidates for the harness's fixture saves, once we can load one on
  every platform.
- Two mods publish their source: GameBurrow's on GitLab
  (`GameBurrow/TF3_DestinationDisplays`).
