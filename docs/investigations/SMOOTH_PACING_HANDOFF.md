## Proven causes and useful fixes

1. Native simulation/render scheduling and room release scheduling are separate. Baseline 4x averages approximately 20 updates/s but often presents eight updates over a 400 ms native interval. Checkpoint-short batches followed by catch-up batches produce large instantaneous motion changes despite correct average rate. Recorded baseline body velocity included approximately 108.5→10.4→90.8 px/s pulses. Measurements of native-call elapsed wall time and all-thread process CPU are separate; wall time is not CPU utilization.
2. Room speed notices received before world load were previously drained without refreshing the experimental scheduler. This startup bug is fixed. The experimental policy derives cadence from authoritative room SPS/speed, not local requested speed.
3. GameSim runs on a worker; CGame Step/Sync run on the presentation thread. Initial per-thread/frame-active accounting and worker timer writes were wrong. Current code publishes cumulative counters atomically and confines native timer/alpha writes to verified CGame Step/Sync hooks. Lifecycle identity reset and post-consumption capped lookahead defects were also fixed and independently verified.
4. One-update callbacks at 20 Hz incurred asynchronous readiness/false-Sync losses: loaded capture could sustain only about 17–19 Hz although idle trials reached 20. Stock 200 ms presentation batches provide more readiness headroom. Short one-update checkpoint batches can still leave the following batch unready before the next deadline. Speeding the timer blindly does not solve this pipeline.
5. Ordinary commands create a replay barrier: driver requests GUI/Lua replay, returns zero updates, and later callbacks resume only after acknowledgment. Post-positive staging helps when acknowledgment arrives early, but **does not eliminate late acknowledgment**. J precisely records NotificationSeen event 18, step 6298, token 13, with a 114.687 ms zero presentation window. Native signaling/Sync must not be skipped, and no unsealed update may be invented.
6. Native GameSim prelude copies current model transforms to prior on every callback, including zero. Renderer consumers use these pairs/alpha. Vehicle-specific road vf3 also interpolates MovePath previous/current endpoints. Paused L2 private-vector +5 m test shifted the whole cab/trailer and restored it, while API world position and fixed landmarks remained unchanged: the intercepted road world-vector input causally affects the body.
